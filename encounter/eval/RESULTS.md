## Run history (read this before quoting a number)

- First run of this probe set, before any change prompted by it: **39 / 48** probes passed, **9 / 12** consistency groups, 0 unsupported sentences.
- The failures were matcher errors (a long phrase hiding a second named topic, single words matching inside longer phrases, missing paraphrases for radiation / aggravating / relieving / occupation / delay in seeking care). The matcher and taxonomy were then fixed using these same probes, so the figures below are **development-set figures**, not held-out ones. The remaining failures are left as they are.
- Round 2 (after the independent QA pass): the patient now gives a plain "no" to yes/no questions on topics the case does not define (ledger result `answered_negative_by_default`, switchable per case), so the two 'absent' probes now expect that result instead of `not_specified`.
- A blind held-out check still does not exist: someone other than the author should write 30 new probes and run this script unchanged.

## What was not measured

- The online paths (Bedrock, Anthropic) were not run against the real services: no credentials were present. They are exercised in the test suite against faked responses only.
- No human review of clinical plausibility, no faculty labels for the grader, no observer usability sessions.
- The unsupported-claim check is structural (sentence is authored in the case). It cannot detect an authored sentence that is itself clinically wrong.
